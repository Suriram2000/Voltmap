Delete account & data

VoltMapEV privacy choices

Delete inside the app

  1. Open VoltMapEV and select Profile.
  2. Select Delete account & local data.
  3. Review the warning and select Delete permanently.

This immediately removes the profile, locally saved identifier and password hash, favorites, trips, receipts, charger reports, vehicle details, and preferences stored by VoltMapEV on that device. It cannot remove a public GitHub charger report; use GitHub’s controls or contact support with the public issue link.

Request help without the app

Email skotla100@gmail.com with the subject “VoltMapEV account deletion request.” Do not send passwords, OTPs, payment credentials, Aadhaar, PAN, or banking documents. The current release has no central VoltMapEV account server; support will explain whether any public submission needs separate removal.

Future cloud accounts

If synchronized cloud accounts are introduced, this page and the in-app flow will be updated to delete server-side account data and request deletion from applicable service providers.
